Publish your app

  1. Create a GitHub accountFree, at github.com/signup
  2. Create a repositoryClick New and name it after your app
  3. Build a signed release APKAndroid Studio: Build, Generate Signed App Bundle / APK, APK. Debug builds are rejected
  4. Publish a releaseOn your repo: Releases, Draft a new release, attach the APK, Publish. One APK per release
  5. Submit your repo belowWe review it and add it to the store

Keep your signing key safe. Every update must be signed with the same key.
